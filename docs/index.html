Urban Duty — Native Police Simulator

Independent police simulation project built from the ground up with C++20, CMake and Vulkan.

Current status

The project is in active engine and build-system development. Windows and Android targets are being built from a shared native architecture. A production-ready APK or full game release is not claimed until the corresponding CI artifacts pass verification.

Project goals

  • Windows and Android support from a shared native codebase.
  • Custom engine architecture rather than Unity, Unreal or Godot.
  • Physically grounded vehicle, traffic, NPC and police simulation.
  • High-fidelity PBR/HDR rendering with scalable performance targets.
  • Extensive menus, settings, controls, tutorial, save/load and accessibility systems.
